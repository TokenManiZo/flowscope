지금 할 일

Burp의 FlowScope 탭에서 허가된 exact scope를 적용하세요.

  1. Burp FlowScope 탭에 http(s)://host[:port]/path-prefix를 입력합니다.
  2. 범위 적용을 누릅니다.
  3. Proxy listener는 HUMAN 127.0.0.1:8080, ZAP 127.0.0.1:8081을 사용합니다.

테스트 계정 등록

표시 이름·역할·대상 서비스만 등록합니다. 로그인 캡처 중 받은 쿠키·토큰은 Burp 프로세스 메모리에만 유지되고 프로젝트 파일에는 저장되지 않습니다.
