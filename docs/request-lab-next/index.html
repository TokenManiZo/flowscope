첨부 화면의 두 줄을 제거합니다.
서비스 전체 주소와 소속 API 설명을 매 결과에 반복 표시하지 않습니다.
  • 종류 + 노드 이름을 한 줄로 표시
  • 각 결과의 경계선·여백·호버·키보드 선택을 분리
  • 같은 이름만 짧은 서비스 표시를 제안
  • 검색 범위·결과 선택·배치 유지 동작은 유지
사용자 선택: 같은 이름일 때만 host:port 표시.
