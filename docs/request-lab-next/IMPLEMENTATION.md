# 승인 UI 구현 기록

- 승인: 2026-10-04, 이 목업으로 진행.
- 기준: 로컬 `FEAT/graph-stage-02`, 구현: `FEAT/request-lab-ui`.
- 대상: Request Lab, 검색 결과 표시, 객체 집중 펼침. 데스크톱만.
- 빌드·TypeScript·Vitest·Playwright·실제 Burp·성능 측정은 실행하지 않았다. 아래는 사용자가 실행할 검증 항목이며 통과 결과가 아니다.

## 변경과 설계 선택

Request Lab의 인증·글자·창/패널 확대를 상단에 통합했다. 주소 전용 행을 추가하지 않는다. 기본 14px, 동일 편집기를 유지하며 본문만 스크롤한다. 분할선은 CSS 변수로 드래그 중 반영하고 놓을 때 React 상태를 확정한다. Raw 색칠은 값이 바뀔 때만 다시 계산한다.

JSON 정돈은 토큰 사이 공백만 바꾸는 문법 검증 formatter다. 숫자 정밀도·중복 key·escape를 바꾸는 `JSON.parse → stringify`를 사용하지 않는다. 본문 256KiB, 중첩 128, 출력 1MiB 한도이며, 정돈 결과 64KiB 초과 시 토큰별 색칠 대신 텍스트를 사용한다. 파생 보기는 대화상자의 메모리 소유자에 두고 닫기·데이터 교체·unload 때 함께 비운다. 인증/전송 요청과 서버 scope guard는 기존 경로를 사용한다.

검색은 전체 일치 결과에서 같은 종류·이름의 서비스 중복을 판단한다. 화면 제한 밖에 중복이 있어도 처음부터 host:port를 표시하고, 같은 host:port의 scheme 차이는 주소로 구분한다. 중복 이름별 구분값은 한 번 계산한다. 전체 주소와 소속은 접근성 설명/tooltip에 유지한다.

객체는 별도 창 대신 실제 Cytoscape 카드·관계선을 사용한다. 묶음 기준 자동 위치는 일반 저장에서 제외하고 기존 저장 위치를 삭제하지 않는다. 명시적 드래그/크기 조절은 저장한다. 열려 있는 동안 직접 바꾼 위치는 snapshot/테마 갱신에도 유지하고, 다시 펼칠 때는 묶음 가까이에 표시한다. 객체 펼침은 보기 메모리 상태 하나로 관리하며 기존 프로젝트의 객체 펼침 항목을 자동 복원하지 않는다. API 묶음 저장은 유지한다. 검정 집중 표시, 관계선의 앞쪽 순서, 접힘을 연결하며 새 관계나 Evidence를 생성하지 않는다.

## 직접 검증 순서

1. 저장한 진단의 관측 기록에서 Request Lab을 연다. 상단 인증·글자·확대와 Raw/JSON 버튼을 확인한다.
2. 요청 초안을 바꾸고 기본/최대화/요청 확대/응답 확대/함께 보기/글자 크기를 왕복한다. 초안·선택·스크롤을 확인한다. 확대 중 Esc는 기본 창으로 돌아가야 한다.
3. 긴 Raw·정돈 JSON으로 박스 내부 스크롤과 고정 높이를 확인한다. 분할선 드래그·방향키·Home·double-click을 확인한다.
4. 큰 정수, 소수 끝 0, escape, 중복 key, 잘못된 JSON, 비JSON, 잘린/큰/깊은 본문을 확인한다. 보기 전환만으로 전송하지 않으며 수동 전송 값은 Raw와 같아야 한다.
5. 닫기·프로젝트 교체·늦은 응답·세션 소멸·snapshot 오류에서 기존 메모리 정리와 전송 잠금을 확인한다. 인증 상세/전송 이력은 처음 접혀 있다.
6. 검색의 한 줄 경계, 중복/단일 서비스, 같은 host:port의 scheme 차이, 30개 더 보기, IME·방향키·Enter를 확인한다.
7. 객체 묶음을 더블클릭/Enter로 펼친다. 멤버가 가까이 표시되고 ID → API → OBJ 연결과 기존 신원/API 좌표를 유지해야 한다. 다른 객체와 겹침을 허용한다.
8. 멤버 선택·상세 패널 조작은 펼침을 유지한다. 배경·Esc·다른 노드/엣지·메뉴·계층·목록 전환·Request Lab 열기는 접힘과 밝아짐을 함께 수행한다.
9. 펼친 멤버 드래그/크기 조절 후 snapshot·테마 변경을 확인한다. 접기/재펼침·프로젝트 재열기에서 객체는 접혀 시작하고 기존 저장 좌표가 자동 배치로 덮이지 않아야 한다.
10. 라이트/다크, 1280/1920px, 작은 창 높이, 100%/125% 배율, Mac/Windows 입력과 큰 데이터 지연을 확인한다.

자동 검사 실행은 저장소 루트에서 `mvn clean verify`로 수행한다. 회귀 검사는 Request Lab 초안·파생 보기 정리, JSON 토큰/한도, 검색 중복, 실제 객체 배치/저장 제외와 접힘 전환을 추가했다. JSDOM 검사는 실제 드래그 좌표나 CSS 높이 검증을 대체하지 않는다.
