검토 순서와 승인 경계

최신 QA_TEMP에서 만든 단일 브랜치에서 작업별 커밋으로 진행합니다. UI 배치·표시·기존 데이터 연결은 승인되었으며 실제 기능 변경은 별도 확인합니다. QA_TEMP 병합 승인은 별개입니다.

  1. 계정·수집: 출처별 누적 수집 건수와 시작·종료 안내
  2. LLM: 진행과 종료 결과 분리, 추가 지시 접수 확인
  3. API·입력 차이: 출처별 차이와 관측·선언 근거
  4. 관측 기록: 메서드·경로·상태 열 분리, 원문 우선
  5. 그래프: 사용자 요청으로 보류
  6. 통합 검증: 승인한 화면과 실행 흐름 확인

모바일 버전은 만들지 않습니다. 목업의 시작·전송·저장 동작은 브라우저 안의 시뮬레이션입니다.
