# 사이드바 메뉴 정리

2026-10-03 · FIX/UI_UX · 기준 533ed58

- 교차 신원 검증을 독립 메뉴에서 부가 기능으로 이동한다.
- 취약점 시나리오와 실행 상태는 사이드바 메뉴에서 제거한다.
- 독립 메뉴: 점검 시작 / 계정·세션 / 점검 Gap 그래프 / 권한 매트릭스.
- 부가 기능: API·입력 차이 / 교차 신원 검증 / 관측 기록.

`navigation-review.html`의 라이트·다크 전후 목업을 먼저 제시한 뒤 반영했다. 메뉴 배열과 관련 기존 테스트의 기대값, README만 갱신했다. 기존 화면 경로와 기능 코드는 유지했다.

사용자가 직접 검증하기로 요청하여 이번 변경에는 테스트·웹 QA를 실행하지 않았다. 앞선 상세 UI의 검증 결과를 이번 메뉴 변경의 검증으로 간주하지 않는다. 웹은 `npm run build`, JAR는 `mvn -DskipTests -Dskip.npm=true -Dskip.installnodenpm=true package`로 빌드했으며 성공했다. `graphify update .`는 코드 관계 그래프 유지보수를 위해 실행했다. QA_TEMP 병합은 별도 승인 대기다.

## Maven 프론트엔드 검증 실패 후속 수정

사용자 빌드 실패 보고 이후 프로젝트에 고정된 Node로 `npm run verify`를 실행했다. 타입 검사는 통과했지만 기존 테스트 2개가 변경 전 메뉴를 기대하여 실패했다(618개 통과·2개 실패).

- `DashboardPage.test.tsx`: 교차 신원 검증을 부가 기능에서 열도록 수정하고, 숨긴 두 메뉴 링크가 없음을 확인한다. 기존 직접 주소 진입 검증은 유지한다.
- `VerificationPage.test.tsx`: 교차 신원 검증이 독립 메뉴 대신 부가 기능에 속하는지 확인한다. 기존 route/hash와 실제 페이지 렌더링 검증은 유지한다.

제품 코드와 UI는 변경하지 않았다. 이 후속 수정의 검증 결과는 최초 메뉴 변경 때 생략한 검증과 구분한다.

수정 후 루트 `mvn clean verify`의 타입 검사·프론트엔드 620개·Java 792개(실패/오류 0, 기존 실제 연동 3개 제외)가 통과했다. 최종 JAR 검사 도중 같은 프로젝트의 별도 `mvn clean`이 JAR와 테스트 클래스를 삭제하여 전체 명령은 실패했다. 해당 빌드 종료 후 `mvn -e exec:java@verify-release-jar`를 다시 실행해 14:21 KST에 성공했다. 전체 명령 성공과 단계별 검증 성공을 구분해 기록한다. `graphify update .`도 완료했다. 실제 웹 QA는 추가 실행하지 않았다.
