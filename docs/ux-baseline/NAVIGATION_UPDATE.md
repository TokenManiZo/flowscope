# 사이드바 메뉴 정리

2026-10-03 · FIX/UI_UX · 기준 533ed58

- 교차 신원 검증을 독립 메뉴에서 부가 기능으로 이동한다.
- 취약점 시나리오와 실행 상태는 사이드바 메뉴에서 제거한다.
- 독립 메뉴: 점검 시작 / 계정·세션 / 점검 Gap 그래프 / 권한 매트릭스.
- 부가 기능: API·입력 차이 / 교차 신원 검증 / 관측 기록.

`navigation-review.html`의 라이트·다크 전후 목업을 먼저 제시한 뒤 반영했다. 메뉴 배열과 관련 기존 테스트의 기대값, README만 갱신했다. 기존 화면 경로와 기능 코드는 유지했다.

사용자가 직접 검증하기로 요청하여 이번 변경에는 테스트·웹 QA를 실행하지 않았다. 앞선 상세 UI의 검증 결과를 이번 메뉴 변경의 검증으로 간주하지 않는다. 웹은 `npm run build`, JAR는 `mvn -DskipTests -Dskip.npm=true -Dskip.installnodenpm=true package`로 빌드했으며 성공했다. `graphify update .`는 코드 관계 그래프 유지보수를 위해 실행했다. QA_TEMP 병합은 별도 승인 대기다.
