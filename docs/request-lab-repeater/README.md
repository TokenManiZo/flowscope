# Request Lab · 요청 편집 목업

[상호작용 목업](index.html) · [제품 설계](DESIGN.md)

처음에는 `Original | +`만 보인다. +를 누르면 `Original | 요청 1 ▼ | × | +`가 나타나고 바로 수정·재전송한다. 다시 +를 누르면 현재 요청을 복사해 요청 2, 3, …를 추가한다. 드롭다운에서 요청을 바꿔도 각 편집 내용과 마지막 응답을 유지한다. Original은 읽기 전용이다.

각 요청은 **현재 REQ와 마지막 RES 하나만** 보관한다. #번호·HTTP 상태 이력 선택, 당시 편집 요청 읽기 전용, 과거 결과 보기와 재전송 이력 배열은 제거했다. 재전송이 끝나도 요청은 계속 편집한다. 응답은 읽기 전용이며 새 결과가 오면 교체한다. ×는 선택한 요청과 응답을 지우고, 마지막 요청을 지우면 처음 상태로 돌아간다.

모든 데이터와 응답은 합성 예시다. 버튼을 눌러도 실제 HTTP 전송·프로젝트 저장·Burp 연동은 없다. 승인된 요청 추가·삭제와 마지막 응답만 유지하는 흐름을 제품에 반영했다. 제품 빌드·테스트·Burp 검증은 사용자가 수행하며 아직 실행하지 않았다.

```sh
python3 -m http.server 18849 --bind 127.0.0.1 --directory docs/request-lab-repeater
```

`http://127.0.0.1:18849/`에서 비교한다. Original·드롭다운은 104×28px, +·×는 28×28px다. 오른쪽 요청 재전송 버튼은 중앙 정렬했다. 요청·응답 내부 스크롤, 라이트·다크, 글자 크기, 창·패널 확대, 같은 칸의 색상 JSON 보기는 유지한다.
