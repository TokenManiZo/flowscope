# 기여 안내

버그 신고, 사용 문서 개선, 코드 기여를 환영합니다. 보안 취약점은 공개 이슈 대신 [보안 정책](../SECURITY.md)의 비공개 신고 절차를 따라 주세요.

## 변경하기

1. [README](../README.md)와 영향받는 코드·테스트를 읽습니다.
2. 한 가지 목적에 필요한 부분만 변경합니다. 관련 없는 리팩터링이나 포맷 변경은 분리합니다.
3. 버그 수정에는 재현하는 회귀 테스트를, 새 동작에는 필요한 테스트를 포함합니다.
4. 설치·운영·사용자 동작이 바뀌면 README 또는 관련 사용 문서와 [미배포 변경 기록](releases/unreleased.md)을 갱신합니다.

## 검증하기

저장소 루트에서 실행합니다. JDK 21과 Maven 3.9.x가 필요하며 Node.js는 Maven이 내려받습니다.

```bash
mvn clean verify
```

CI는 Maven 검증과 배포 파일 구성·재현 빌드를 확인하고, Bash 스크립트의 구문·ShellCheck와 PowerShell 스크립트 파싱을 검사합니다.

## Pull Request

변경 목적을 나타내는 작업 브랜치에서 PR을 만듭니다. 본문에는 다음을 적어 주세요.

- 문제와 변경 후 동작, 연결된 이슈
- 영향 범위와 중요한 설계 선택·기각한 대안
- 실제 수행한 검증과 남은 한계

자동 테스트와 실제 Burp·ZAP 실행 검증은 구분하고, 수행하지 않은 검증을 완료했다고 적지 않습니다.

## 데이터 취급

실제 점검 대상의 트래픽·자격증명, 개인 프로젝트 DB, `.env`, 키 파일과 로컬 도구 기록은 커밋하지 않습니다. 예제와 스크린샷에는 샘플 데이터를 사용하고, 커밋 전 `git status`로 포함 파일을 확인합니다.
