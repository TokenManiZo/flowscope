# 패널 조작 개선 목업

새 브랜치 `FIX_UI_PANEL_INTERACTION`, 기준 `origin/QA_TEMP 8357e20`.

제품 소스 변경 전 보여주는 독립 데스크톱 목업이다. 개선 전은 QA_TEMP의 배치·조작을 예시 데이터로 재구성한 화면이며 실제 제품 캡처가 아니다. 전후는 같은 계정·API·수치를 사용한다. 실제 조회·로그인·ZAP 실행은 없다.

1. API 상세: 이미 선택된 항목의 패널을 접은 뒤 상세 보기를 다시 눌러도 펼쳐지지 않는 상태를 재현한다. 개선 후에는 상세 보기 클릭으로 선택과 패널 열기를 함께 수행한다. 패널을 다시 접고 같은 행을 눌러도 다시 열린다.
2. 사이드바: 펼친 상태의 부가 기능 그룹은 유지한다. 접힌 상태에는 API·입력 차이, 교차 신원 검증, 관측 기록의 아이콘과 메뉴명 툴팁을 직접 제공한다. 전체 사이드바를 펼치지 않고 이동할 수 있다.
3. ZAP: LLM 계정 영역과 동일하게 제목 줄은 12px 글자·좌우 12px/상하 8px 여백·기본 배경으로 표시한다. 펼친 본문에는 12px 안쪽 여백과 독립된 계정 표를 둔다. 표 머리글은 36px 높이·12px 글자로 LLM과 맞춘다. 제목 줄 전체를 클릭·키보드 조작할 수 있다. 선택 계정 요약과 기존 ZAP 설정 버튼을 유지한다. 표의 체크박스·설정 버튼은 접기 동작과 독립적이다.
4. 원문 보기: 본문 padding이 0인 창에 공통 DialogFooter의 음수 margin이 적용돼 닫기 버튼이 오른쪽 아래 테두리에 붙는다. 이 창의 footer에서만 margin을 0으로 재정의하고 좌우 20px·상하 8px 여백을 둔다. 오른쪽 아래 위치와 닫기 동작은 유지한다.
5. 하단 버튼 영역: `DialogFooter` 사용 4곳, `AlertDialogFooter` 사용 5곳, 계정 등록·설정의 독립 footer 2곳을 확인했다. 모두 상하 여백 8px로 맞춘다. 공통 컴포넌트는 `p-4` 대신 `px-4 py-2`, 독립 계정 footer는 `py-3` 대신 `py-2`, 계정 삭제의 `py-2.5` override는 제거한다. Request Lab의 sticky·margin 재정의는 유지한다. 버튼 높이 32px, 기존 좌우 여백, 8px 버튼 간격, 확인 문구·확인 단계·동작은 보존한다.

| 적용 대상 | 현재 상하 여백 | 개선 후 |
| --- | --- | --- |
| 원문 보기 | 16px + 음수 margin으로 일부 잘림 | 8px, 음수 margin 제거 |
| Request Lab | 16px | 8px |
| XML 가져오기 | 16px | 8px |
| 새 프로젝트 | 16px | 8px |
| 계정 등록·계정 설정 | 각각 12px | 각각 8px |
| 계정 삭제 | 10px | 8px |
| 프로젝트 삭제·현재 프로젝트 전환 후 삭제 | 각각 16px | 각각 8px |
| 기록 비우기·저장하지 않고 닫기 | 각각 16px | 각각 8px |

`screen=footer-audit`은 위 11곳의 하단 버튼 영역만 재구성한 비교표다. 각 창 전체를 재현한 제품 화면은 아니다. 실제 프로젝트/계정 생성·삭제·전송·가져오기는 실행하지 않는다. 본문 정보·입력·일반 페이지/카드 여백은 이번 범위에 포함하지 않는다.

데스크톱 1280×720 / 1920×1080, 전후 라이트·다크 4종 비교, 상세 열기·접기, 메뉴 이동, 계정 접기·선택 동작을 제공한다. 모바일은 작업 범위가 아니다. 전체 빌드 및 실제 제품 화면 검증은 사용자가 직접 진행한다.

제품 구현과 QA_TEMP 병합은 이 목업 확인 후 별도로 진행한다.
