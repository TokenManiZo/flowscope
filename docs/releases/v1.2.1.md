# FlowScope v1.2.1

태그일: 2026-10-14

[GitHub Release](https://github.com/TokenManiZo/flowscope/releases/tag/v1.2.1) · [v1.2.0 이후 변경](https://github.com/TokenManiZo/flowscope/compare/v1.2.0...v1.2.1)

대시보드·수집 기록·판정 화면의 가독성을 높이고, 그래프 필터와 미니맵 조작을 개선했습니다.

## 주요 변경

- **화면 가독성**: 대시보드, 계정·수집 화면, 판정 매트릭스, Request Lab의 글자·버튼 크기와 행 간격을 조정했습니다.
- **그래프 조작**: API 카드와 필터 표시를 확대하고, 필터 설명과 건수를 정리했습니다. 오른쪽 상세 패널의 너비를 조절할 수 있습니다.
- **미니맵 상태 유지**: 접기·펼치기 상태를 화면 이동과 그래프 갱신 중에도 유지합니다. 다른 프로젝트를 열면 펼친 상태로 시작합니다.
- **LLM 판정 진행 기록**: HTTP 응답 상태를 요청 요약 옆에 표시해 결과를 쉽게 읽도록 했습니다.
- **프로젝트 관리**: 사이드바의 프로젝트 관리 버튼을 눌렀을 때 메뉴가 닫히면서 관리 창이 사라지는 동작을 수정했습니다.

## 설치·업그레이드

`flowscope-1.2.1-bundle.zip` 또는 `flowscope-1.2.1.jar`를 사용합니다. 프로젝트를 저장한 뒤 이전 확장을 제거하고 새 JAR 하나만 추가하세요. Burp 재시작 후 계정 로그인은 다시 연결해야 합니다.
