# FlowScope v1.2.0

배포일: 2026-10-14

[GitHub Release](https://github.com/TokenManiZo/flowscope/releases/tag/v1.2.0)

프로젝트 시작 주소와 점검 범위를 분리하고, LLM 판정 결과와 객체 그래프를 개선했습니다.

## 설치

- 전체 구성: `flowscope-1.2.0-bundle.zip`
- Burp 확장 JAR: `flowscope-1.2.0.jar`
- 파일 무결성: `SHA256SUMS.txt`

## 주요 변경

- 프로젝트의 시작 URL을 계정·LLM·ZAP 브라우저의 기본 주소로 사용합니다. `*.example.com`을 점검 범위에 추가하면 루트와 하위 도메인을 포함합니다.
- LLM 판정 결과를 취약·확인 필요·정상·미판정으로 구분하고, 판정 요약과 실제 요청 근거를 확인할 수 있습니다.
- 판정 매트릭스에서 제외한 항목은 LLM 판정 대상에서도 제외합니다.
- 그래프에서 한 요청의 PATH·QUERY·BODY 입력을 객체 하나로 묶고, 객체 묶음의 소유 설정을 하위 객체에 적용합니다.
