# FlowScope v1.0.1

태그일: 2026-10-07

[GitHub Release](https://github.com/TokenManiZo/flowscope/releases/tag/v1.0.1) · [v1.0.0 이후 변경](https://github.com/TokenManiZo/flowscope/compare/v1.0.0...v1.0.1)

Request Lab의 원문 확인·재전송 흐름을 정리하고, ZAP 인증 설정과 그래프 필터를 개선했습니다.

## 주요 변경

- **원문 저장**: 요청·응답의 자동 마스킹을 제거하고 원문을 저장합니다. 저장한 요청을 다시 열어 편집·재전송할 수 있습니다.
- **Request Lab 통합**: 수집 기록에서 같은 Request Lab을 열고, 요청·응답 검색과 직접 입력 요청의 저장을 지원합니다.
- **ZAP 인증값 주입**: 쿠키·헤더로 로그인 상태를 연결하고 검증 URL로 확인하는 방식을 추가했습니다.
- **계정별 수집**: 선택한 계정을 기준으로 요청을 연결하고, HUMAN 수집에서 Burp Intercept와 실제 전송된 인증값을 반영합니다.
- **그래프 필터**: 객체 보기에서도 계정 필터를 유지하고, 일치하는 노드를 위쪽에 배치합니다.
- **LLM 브라우저**: Burp 프록시를 거쳐 트래픽을 수집하고, 비로그인 탐색은 명시적으로 선택하도록 변경했습니다.

## 업그레이드 주의

- 이 버전부터 프로젝트·JSON 내보내기에 쿠키·토큰·비밀번호가 원문으로 포함될 수 있습니다. 점검 기록을 공개하거나 그대로 공유하지 마세요.
- 이전 버전에서 마스킹해 저장한 값은 복원되지 않습니다. Request Lab에서 해당 값을 확인하고 실제 값으로 교체해야 합니다.
- LLM 탐색에는 응답 원문이 전달될 수 있습니다.
