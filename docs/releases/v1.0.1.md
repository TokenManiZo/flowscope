# FlowScope v1.0.1

배포일: 2026-10-07

[GitHub Release](https://github.com/TokenManiZo/flowscope/releases/tag/v1.0.1)

Request Lab의 **직접 입력** 저장 문제를 고치고, 쓰지 않는 예전 화면과 기능을 정리한 패치 버전입니다.

## 설치

- 처음 설치: `flowscope-1.0.1-bundle.zip` (JAR·ZAP 구성·실행 스크립트)
- JAR만 설치: `flowscope-1.0.1.jar`
- 파일 무결성 확인: `SHA256SUMS.txt`

설치와 첫 점검은 [README](../../README.md#설치)를 참고하세요.

## 수정

- Request Lab에서 전송 인증을 **직접 입력**으로 보낸 요청이 있으면 자동 저장이 실패하고(저장 실패), 닫기를 누를 때마다 **변경 버리고 닫기** 확인이 뜨던 문제를 고쳤습니다. 직접 입력 탭도 다른 모드와 똑같이 저장됩니다. 저장본에서 인증값은 다른 모드와 마찬가지로 가려 둡니다.

## 제거

- 전환 기간에 남겨 두었던 예전 웹 화면(`http://127.0.0.1:17777/legacy/`)을 없앴습니다. 웹 화면은 `/`와 `/app/`의 현재 화면 하나입니다.
- 현재 화면에서 쓰지 않던 로컬 API `/api/clear`, `/api/cluster-evidence`, `/api/verdict`, `/api/replay-verdict`를 없앴습니다. HAR 가져오기(`/api/import-har`)는 그대로입니다.

## 업그레이드 주의

- 프로젝트 저장 형식은 바뀌지 않았습니다. v1.0.0에서 만든 프로젝트를 그대로 엽니다.
- 확장을 다시 불러온 뒤에는 열려 있던 FlowScope 웹 화면을 새로고침하세요. 접근 토큰이 새로 만들어져, 이전 화면에서 보내는 요청은 거부됩니다.
