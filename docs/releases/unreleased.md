# 다음 릴리스 (미배포)

## 주요 변경

### 요청·응답을 가리지 않고 원문 그대로 저장

요청·응답에서 인증값과 비밀 필드를 `***MASKED***`로 가리던 기능을 없앴습니다. Authorization, Cookie, Set-Cookie, password, token, API key도 다른 값과 똑같이 원문 그대로 저장하고 화면에 보여 줍니다.

- Burp나 확장을 다시 시작하거나 프로젝트를 다시 열어도, 저장된 원문으로 Request Lab에서 바로 편집하고 다시 보낼 수 있습니다. 저장 상한을 넘었거나 바이너리라 일부만 남은 기록만 보낼 수 없습니다.
- 가려진 값이 남아 있다는 이유로 Request Lab 전송을 막지 않습니다. 저장해 둔 Request Lab 탭도 쓴 인증값 그대로 다시 열립니다.
- 이름에 password·token·secret 등이 들어간 파라미터도 API·입력 차이와 관측 근거에서 다른 파라미터와 똑같이 보입니다.

### 수집 기록도 Request Lab으로 확인

점검 시작의 **수집 기록**과 **ZAP 요청 기록**에서 요청 행을 누르면 읽기 전용 **원문 보기** 창 대신 그래프·판정 매트릭스와 같은 **Request Lab**이 열립니다. 기록을 보는 곳이 Request Lab 하나로 합쳐져, 원문을 확인한 자리에서 바로 고쳐 다시 보낼 수 있습니다.

### Request Lab 요청·응답 검색

Request Lab 제목 옆에 검색 칸을 두었습니다. 긴 요청·응답에서 글자를 찾으면 찾은 곳을 모두 표시하고 `2 / 5`처럼 위치를 알려 줍니다. Enter·Shift+Enter나 위·아래 버튼으로 이동하면 그 줄로 스크롤하고, Ctrl+F로 검색 칸에 바로 가며, Esc로 검색어를 지웁니다. 대소문자는 가리지 않고, 요청 확대·응답 확대 중에는 보이는 쪽에서만 찾습니다.

### ZAP 로그인에 인증값 주입 추가

MFA·SMS·SSO처럼 ZAP이 폼으로 자동 로그인할 수 없는 사이트를 위해, 직접 로그인해서 얻은 **쿠키나 인증 헤더**를 넣어 그 세션으로 점검하는 방식을 추가했습니다. 계정 **관리 → ZAP 로그인**에서 **로그인 방식**을 폼 로그인(ID·비밀번호)과 **인증값 주입** 중에 고릅니다.

- 쿠키는 ZAP 세션 쿠키잔에 심어 Set-Cookie 회전을 따라가고, 인증 헤더는 ZAP Replacer 규칙으로 크롤·스캔 요청마다 붙인 뒤 스캔이 끝나거나 실패·취소되면 지웁니다. 주입값도 Burp 프로세스 메모리에만 둡니다.
- **검증 URL**(선택)과 **주입값 검증** 버튼으로, 로그인해야 열리는 API 주소에 넣은 값을 한 번 보내 로그인 여부를 확인합니다. 2xx면 로그인됨, 401·로그인 리다이렉트면 아님, 404면 주소 오류, HTML 페이지가 오면 화면 주소일 수 있어 보류로 봅니다. 검증 URL은 대상과 같은 호스트만 허용하며 스캔 순서와 무관한 1회 사전 점검입니다.
- MFA·SSO 전체 재인증은 자동화되지 않습니다. 주입 세션의 실제 인증·갱신 효과는 사이트마다 다르므로 실제 점검으로 확인하세요.

### API·입력 차이에서 발견 URL 내보내기

`API·입력 차이` 화면 제목 줄에 **URL 내보내기** 버튼을 넣었습니다. 지금 보이는 목록(체크한 행이 있으면 그 행만)의 URL을 중복 없이 정렬해 `.txt` 파일로 내려받습니다. JS나 robots.txt에서 발견만 되고 아직 요청하지 않은 API(`미관측` 탭, `산출물에서 발견 · 아직 요청 없음` 필터)를 모아 ZAP·LLM 씨앗이나 외부 도구에 넣을 때 씁니다. URL만 담으며 메서드는 넣지 않고, `{id}` 같은 경로 변수는 그대로 적힙니다.

### 기록 번호를 #번호 하나로 통일

같은 기록을 화면마다 "관측 기록", "Evidence", "Evidence ID", "기록 번호"로 다르게 부르던 것을 정리했습니다.

- 메뉴와 화면 문구의 "관측 기록"을 **요청 기록**으로 바꿨습니다. Request Lab 전송 결과, ZAP·LLM 진행 문구, 오류 메시지처럼 서버가 보내는 문구의 "Evidence"도 "요청 기록"으로 바꿨습니다.
- 기록은 어디서나 `#12`처럼 번호로만 표시합니다. 경로 후보 상세, 기록 상세, 시나리오, 흐름 링크, LLM 탐색 진행 기록에 그대로 보이던 긴 내부 ID(`ev-3f9a…`)를 번호로 바꿨습니다.
- 삭제됐거나 지금 분석에 없는 기록은 열 수 없어서 목록에서 빼고 건수에도 넣지 않습니다. 남은 기록이 하나도 없으면 "요청 기록" 줄 자체를 보여 주지 않습니다.
- 실행 상태의 지난 실행은 `zap-baseline-…` 같은 실행 ID 대신 `ZAP 실행 · 10/07 14:32`처럼 도구와 시작 시각으로 보여 줍니다. 원래 ID는 마우스를 올리면 보입니다.

### 계정·미점검으로 이름 통일

같은 대상을 여러 이름으로 부르던 것을 하나로 맞췄습니다.

- **계정**: 신원, identity, IDENTITY, 트래픽 신원, 관측 신원, 보낸 신원을 모두 "계정"으로 부릅니다. 그래프 열 머리글과 카드 배지의 `IDENTITY`도 "계정"으로 바꿨고, 등록하지 않은 계정으로 로그인한 요청은 "미등록 로그인 1" 대신 "등록 안 된 계정 1"로 표시합니다. 서버가 보내는 판정 사유·ZAP 진행 문구도 같은 말로 바꿨습니다.
- **미점검**: 아직 시험하지 않은 계정·API·입력 조합을 Gap, 갭, 열린 Gap, 공백, 미실행, 권한 변형 미검증으로 부르던 것을 "미점검"으로 통일했습니다. 대시보드는 "미점검 N", "미점검 파라미터", "권한 변형 미점검"으로, 권한 표 필터는 "미점검만 표시"로 보입니다.
- 메뉴 이름(점검 Gap 그래프 등)은 아직 그대로입니다. 메뉴 이름은 따로 정리합니다.

## 수정

- 판정 매트릭스의 **Request Lab에서 보내기**가 편집·재전송할 수 없는 기록을 열던 문제를 고쳤습니다. 판정 근거가 된 처음 기록에 보낼 수 있는 원문이 없으면(저장 상한을 넘었거나 바이너리라 원문이 일부만 남은 기록), 같은 API에서 보낼 수 있는 최신 기록을 엽니다. 같은 신원·같은 객체를 먼저 고르고, 다시 보낸 기록은 고르지 않습니다.
- Request Lab이 원문이 일부만 남은 기록을 열면, 편집·재전송할 수 없는 이유와 다시 보내는 방법(그 API를 한 번 더 둘러본 뒤 새 기록에서 열기)을 눈에 띄게 알려 줍니다.
- 원문이 일부만 남아 편집할 수 없는 기록에서 **편집으로 돌아가기**가 눌러도 아무 반응이 없던 문제를 고쳤습니다. 돌아갈 편집본이 없으면 버튼을 비활성으로 두고 이유를 알려 주며, 원문 안내에서도 "편집으로 돌아가면 고쳐서 보낼 수 있습니다" 문구를 뺍니다.
- Request Lab **전송 인증**의 `인증 선택` 문구를 회색 대신 본문 색으로 표시해, 고를 수 있는 칸으로 보이게 했습니다.
- 점검 시작 **수집 기록**이 ZAP이 아닌 스캐너(예: Burp Scanner)가 보낸 요청까지 "ZAP"으로 표시하던 문제를 고쳤습니다. 이런 요청은 "스캐너"로 표시하고, 그런 요청이 있을 때만 `스캐너` 필터가 나타납니다.
- 그래프 오른쪽 계정별 접근 요약에서 아직 시험하지 않은 API를 "보류"로 표시하던 것을 **미점검**으로 고쳤습니다.

## 업그레이드 주의

- 프로젝트 파일(SQLite)과 JSON 내보내기에 토큰·쿠키·비밀번호가 원문으로 들어갑니다. 비밀 자료로 다루고, 공유하거나 GitHub에 올리지 마세요.
- LLM 탐색을 쓰면 응답 원문이 가려지지 않은 채 Codex로 전달됩니다.
- 이전 버전에서 저장한 기록은 이미 가려진 상태로 저장되어 있어 원래 값으로 되돌릴 수 없습니다. 새로 관측한 기록부터 원문으로 저장됩니다.
- 이런 기록을 Request Lab에서 열면 보낼 요청에 남은 `***MASKED***`·`이름=***`·`[BODY REDACTED: …]`를 빨간 테두리로 표시하고 개수를 경고로 알려 줍니다. 전송은 막지 않으며 표시한 값은 글자 그대로 나가니 실제 값으로 바꿔 보내세요. 계정·비로그인 전송에서는 서버가 바꾸는 인증 헤더(Authorization·Cookie·Proxy-Authorization·CSRF)는 세지 않습니다.
- 계정·세션 화면의 세션 인증값 미리보기(`Bearer eyJh••••`처럼 앞부분만 보이는 표시)는 그대로입니다.
