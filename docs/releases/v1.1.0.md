# FlowScope v1.1.0

태그일: 2026-10-11

[GitHub Release](https://github.com/TokenManiZo/flowscope/releases/tag/v1.1.0) · [v1.0.1 이후 변경](https://github.com/TokenManiZo/flowscope/compare/v1.0.1...v1.1.0)

판정 매트릭스와 객체 그래프를 정리하고, LLM의 교차 계정 재검증 기능을 추가했습니다.

## 주요 변경

- **LLM 교차 계정 검증**: 판정 매트릭스의 추천 요청을 계정 세션으로 재전송하고, 응답에 대한 취약점 소견을 남깁니다. 이 버전의 자동 재전송은 GET만 지원하며 최종 확정은 사람이 합니다.
- **판정 매트릭스**: API별 판정과 계정별 결과를 중심으로 정리했습니다. 확인할 결과 필터, 접근 기준·소유자 설정, 항목 제외·복원을 지원합니다.
- **객체 그래프**: PATH·QUERY·BODY 입력과 응답 객체를 표시하고, 소유자·공개 접근 설정 및 관련 요청 확인을 개선했습니다.
- **Request Lab 연결**: API의 최신 요청과 경로 후보를 Request Lab에서 열어 확인·재전송할 수 있습니다.
- **탐색 지원**: 브라우저에서 발견한 하위 도메인을 그래프에 연결하고, API·입력 차이 화면에서 발견 URL을 내보냅니다.
- **화면 정리**: 계정·미점검·요청 기록 용어를 통일하고, 점검 시작의 결과 비교 탭과 사용하지 않는 화면을 제거했습니다.
- **ZAP 개선**: 주입한 인증 헤더를 크롤링 요청에 반영하고, API 명세 주소 처리와 실패 안내를 개선했습니다.

## 업그레이드 주의

프로젝트·JSON 내보내기에는 요청·응답 원문과 인증값이 포함될 수 있습니다. 이전 버전의 마스킹된 기록은 원래 값으로 복원되지 않습니다. LLM 소견은 취약점 확정과 구분해 검토하세요.
