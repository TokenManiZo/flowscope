## 다음 릴리스

배포 전 변경은 [미배포 변경 기록](unreleased.md)에 모읍니다. 릴리스할 때 정식 태그에 포함된 변경만 버전별 문서로 옮기고, 이 목록에 추가합니다.

사용자에게 영향을 주는 변경을 짧게 기록하며, 해당 버전의 화면 이미지는 `images/<버전>/`에 보관합니다. 배포 절차는 [릴리스 절차](../RELEASE.md)를 참고하세요.
