# 프로젝트 시작 주소와 스코프

새 프로젝트는 실제로 열 사이트 URL을 입력합니다. 이 주소의 호스트가 기본 수집 범위에 포함됩니다. `다른 도메인도 포함`에서 추가 범위를 등록합니다. `*.example.com`은 루트와 모든 하위 도메인을 포함하며, 지정한 프로토콜·포트·경로 조건은 유지됩니다. 와일드카드를 시작 주소에 입력하면 스코프로 옮기고 실제 사이트 주소를 요청합니다.

시작 주소는 계정 세션과 LLM 브라우저 로그인, ZAP 로그인 주소의 기본값입니다. 계정 기본 설정에서 로그인 주소를 별도로 저장할 수 있고, LLM 로그인 입력과 ZAP 설정에서도 수정할 수 있습니다. 이미 개별 저장한 주소는 프로젝트 주소 변경으로 덮어쓰지 않습니다. 계정의 대상 서비스는 로그인 화면 주소와 별도로 유지됩니다.

프로젝트 수정에서도 시작 주소와 범위를 변경합니다. 시작 주소는 범위 안에 있어야 하며, 범위 밖 주소는 저장할 수 없습니다. 기존 프로젝트에 시작 주소가 없으면 HUMAN·LLM 로그인은 빈 브라우저를 엽니다. 자동 서브도메인 열거는 수행하지 않고, 와일드카드 범위에 맞는 실제 브라우저 요청을 수집합니다.
