# 그래프 라이트·다크 표시 보완 목업

2026-10-04 사용자가 목업을 승인하고 추가 분석 후 구현을 요청했다. `FEAT/request-lab-ui`에서 승인한 시각 변경과 아래 회귀 보완을 적용했다. 이번 목업은 객체 집중 펼침의 배경/흐림 표현 보완이며 앱 전체 재설계나 새 기능 단계가 아니다.

## 확정한 방향

사용자 선택: **테마 배경 유지 + 관련 없는 노드 흐리게**.

- 라이트는 기존 밝은 회색 캔버스·흰 카드, 다크는 기존 네이비 캔버스·차콜 카드. 펼쳐도 캔버스 색은 바뀌지 않는다. `frontend/src/index.css`와 `parameterNodeCard.ts`의 현재 팔레트를 기준으로 한다.
- 관련 신원 → API → 객체의 실제 카드/관계선은 선명하게 유지한다. 주변 카드는 기존 12%보다 덜 흐린 **45%**, 주변 선은 **22%**로 적용한다. 목업에서 승인한 값이다. 투명도 변경만으로 기존 위험/출처/응답/소유자 의미를 바꾸지 않는다.
- 선택한 묶음의 얇은 파란 테두리와 기존 묶음 선/접기를 유지한다. 별도 팝업이나 전체 검정 덮개는 추가하지 않는다. 색 외에도 선 굵기와 선택 테두리로 집중을 구분한다.
- 멤버는 현재 방식대로 묶음 가까이 펼치고 주변 객체와 겹칠 수 있다. 멤버·상세 확인은 유지, 배경·다른 노드·Esc·계층/메뉴/Request Lab 이동은 함께 접는다. 모델 좌표·viewport를 테마나 펼침 표현 때문에 바꾸지 않는다.
- 필터, 기존 레인 헤더 정렬과 필터 안 정렬, 검색 한 줄 표시, Request Lab, 저장 형식은 이번 디자인 범위에서 유지한다. 모바일은 제외한다.

## 목업의 사용과 한계

`index.html`에서 라이트/다크, 접힘/펼침, 1280/1920px, 저장 오류 배너를 비교한다. 객체 묶음 더블클릭/Enter로 펼치고 접기·빈 배경·다른 노드·Esc로 접는다. 멤버를 선택하면 펼침이 유지된다. 합성 데이터와 고정 좌표의 SVG/HTML 목업이며 필터·정렬·저장·확대는 제품과 연결되지 않는다. 소유자 미정과 HTTP 200은 취약 여부를 뜻하지 않는다.

실제 screenshot의 **잘못된 그래프 작업 상태**는 제품 저장 오류이며 목업으로 해결했다고 주장하지 않는다. 오류 상태 토글은 기존 문구의 표시 참고다. 실제 실패 응답과 workspace/patch 필드, 동일 프로젝트의 JAR/API/프런트 버전 일치 여부는 추가 확인이 필요하다. 코드에서 확인한 viewport 범위 경로는 아래에 기록한다. 정상 상태 목업은 오류가 고쳐진 제품 실행 캡처가 아니다.

## 적용한 최소 변경과 추가 분석

1. 강제 캔버스 `#020617` 인라인 지정 대신 기존 `--flowscope-canvas` 테마 토큰을 사용한다. 기존 카드 SVG 테마 팔레트를 유지한다. 화면 테마가 바뀌어도 펼침과 선택은 유지한다.
2. `objectFocus=no` 스타일의 opacity를 승인한 값으로 조정하고 기존 관련 노드/엣지 z-index·선택 강조를 유지한다. 검색 일치 카드에는 불투명도를 우선 적용해 읽을 수 있도록 하되 관련 카드의 앞뒤 순서는 유지한다. 전체 검정 overlay, blur/filter, 새 관계선/레이아웃 엔진은 추가하지 않는다.
3. 라이트 그리드가 현재 흰 선이라 잘 보이지 않는 경로를 테마별 기존 토큰 기반 낮은 대비의 그리드로 조정한다. 배경 장식 확대/애니메이션을 넣지 않는다.
4. 요소 재생성 때 `objectFocus`도 초기화한다. 기존에는 테마·잠금·상태 뱃지 등으로 카드가 재생성되면 집중 상태가 빠질 수 있었다. 연결된 신원/API/객체와 주변 카드·선의 상태를 함께 복원한다. 테마 왕복 시 배경에 인라인 검정색이 없고, 연결 강조·모델 좌표·viewport가 유지되며 멤버 선택만으로 요소를 재생성하지 않는 회귀 테스트를 보완했다. 테스트는 실행하지 않았다.
5. Cytoscape 생성 시 `minZoom=0.4`, `maxZoom=2`를 지정한다. 툴바/휠은 이미 범위를 제한했지만 preset/fit은 렌더러 기본 범위를 사용해 서버 `GraphWorkspace.Viewport` 검증 밖의 zoom을 보낼 수 있었다. 렌더러 자체에 기존 범위를 적용하며 서버 검증과 저장 형식은 변경하지 않는다. 실제 screenshot의 오류 원인으로 확정한 것은 아니다. 생성 옵션에 대한 회귀 기대값을 보완했다. 테스트는 실행하지 않았다.

성능: 색·투명도는 Cytoscape 스타일 데이터로 갱신한다. 집중 선택마다 projection/카드 SVG를 다시 생성하지 않는다. 테마 변경에 필요한 기존 카드 팔레트 갱신은 유지하며, 거대한 CSS backdrop-filter나 캔버스 재정렬은 추가하지 않는다. 실제 측정과 빌드/테스트/Burp 검증은 사용자 수행이다.

## 검증 인계

- 실행하지 않음: Maven/npm 빌드, TypeScript/Vitest/Playwright, 제품 UI·실제 Burp 실행. 사용자가 수행한다.
- 목업 화면 확인은 합성 HTML/SVG 표시만 대상으로 하며 제품 검증 결과가 아니다.
- 사용자 확인: 라이트/다크 각각 펼침 → 멤버 선택 → 테마 왕복 → 배경/다른 노드/Esc 접기, 검색 결과 강조와 출처/응답 코드·위험 테두리, 겹친 카드의 선택/모서리 크기 조절, minimap, 계층/화면 왕복 후 좌표 유지.
- 겹친 카드의 일반 클릭은 기존 Cytoscape z-index를 유지한다. 모서리 인식은 기존 화면 좌표 방식이며 정확히 겹친 모서리 조작은 실제 렌더러에서 확인해야 한다. 이번 시각 변경으로 별도 제스처 체계를 추가하지 않았다.
- 작은/큰 그래프의 초기 맞춤 및 맞추기 버튼 이후 zoom이 40~200%이며 저장이 되는지 확인한다. 큰 그래프는 최소 zoom에서 전부 화면에 들어오지 않을 수 있고 기존 캔버스 이동을 사용한다.
- 저장 오류가 계속되면 재시도 응답의 실패 필드와 버전 일치를 확인해야 한다. 저장 검증을 완화하거나 오류 문구를 숨기지 않았다.

제외한 대안: 검정 덮개/전체 blur는 기존 테마와 텍스트 가독성을 해치고 추가 렌더링 비용이 있다. 펼침 시 전체 재정렬은 사용자 배치를 바꾼다. 주변 카드 삭제나 새로운 팝업은 실제 연결 맥락을 잃으므로 채택하지 않았다.
